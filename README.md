# 홈런왕 ⚾ 구단주는 4번 타자

야구 경기, 연애 시뮬레이션, 구단 경영(타이쿤), 2D 오픈월드를 합친 모바일 웹게임입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

주인공은 **25세 재벌 2세**입니다. 서울 애플즈의 **구단주**이면서 **4번 타자 겸 에이스 투수**이고, **도루왕**을 노립니다.

## 시즌 모드 (20주)

### 🏙 오픈월드 도시 (2D 탑다운)
- 화면을 드래그하면 조이스틱이 나와요 (PC는 WASD/방향키). 걸어 다니거나 **슈퍼카를 타고 운전**할 수 있어요.
  - NPC 차량과 행인이 다니고, 급회전하면 드리프트 자국이 남아요.
- 장소 11곳: 펜트하우스, 애플파크(구장), 애플타워(구단 사무실), 스타 스튜디오, 한국대학교, 카페거리, 애플백화점, 한강공원, KBL 심판위원회, 배팅센터, 레스토랑
- 하루는 **오전·오후·저녁** 3번 행동이에요. 장소에서 무언가 하면 시간이 흐르고, 저녁이 되면 밤 조명으로 바뀌어요.
- 3번 행동하면 **주말 경기**를 하러 애플파크로 가요.
- ❗ 표시가 있는 시민에게 말을 걸면 랜덤 이벤트가 생겨요.
- 도시 곳곳에 **황금 야구공 12개**가 숨어 있어요 (모으면 능력치가 올라요).
- 미니맵, 목적지 화살표, 콜택시(빠른 이동)가 있어요.

### 💗 히로인 5명
| 이름 | 직업 | 주로 있는 곳 (오전 / 오후 / 저녁) |
|---|---|---|
| 차유나 | 톱 여배우 | 스튜디오 / 스튜디오 / 레스토랑 |
| 서지우 | 여대생 (스포츠통계학) | 대학교 / 대학교 / 카페 |
| 박하린 | 애플즈 치어리더 응원단장 | 한강공원 / 애플파크 / 백화점 |
| 정세아 | KBL 최초 여성 심판 | 심판위원회 / 심판위원회 / 한강공원 |
| 한소미 | 열성 여성팬 · 유튜버 | 카페 / 배팅센터 / 애플파크 |

- 할 수 있는 것: 대화, 선물(백화점에서 구입), 데이트(장소 9곳). 각자 좋아하는 선물과 장소가 달라요.
- 호감도 35와 60에서 특별 이벤트가 열려요.
- 오래 만나지 않으면 💣 서운함 폭탄이 생기고, 터지면 다른 히로인 호감도까지 내려가요.
- 고백 엔딩 조건:
  - 공통: 호감도 80 이상
  - 차유나: 인기 50 이상
  - 서지우: 선구안 55 이상
  - 박하린: 팬덤 14만 이상
  - 정세아: 공정한 태도를 지킬 것 (판정을 봐달라는 선택지를 고르지 않기)
  - 한소미: 추가 조건 없음

### ⚾ 투타겸업 경기
- **투구**: 구종 선택 → 던질 곳 터치 → 제구 게이지 멈추기. 상대 AI 타자가 코스·구종·볼카운트를 보고 칠지 말지 판단해요.
  - 변화구 능력치가 오르면 커브, 포크볼을 새로 배워요.
- **타격**: 타이밍에 맞춰 공이 지나갈 위치를 터치해요. 히트스톱, 슬로모션, 홈런 불꽃놀이 연출이 있어요.
- **도루**: 1루에 나가면 반응속도 미니게임을 해요. 빨간불에 뛰면 견제사예요.
- 팀 작전(공격적 / 균형 / 수비적), 희생번트, 히트앤런을 고를 수 있어요. 직접 플레이할 수도 있고 자동 진행할 수도 있어요.

### 📈 구단 경영 (타이쿤)
- 티켓 가격, 시설 투자(관중석 / 훈련센터 / 메디컬센터 / 전광판), FA 영입, 마케팅(응원단 지원, 차유나 광고모델, 팬 사인회, 선수단 회식)을 관리해요.
- 경기마다 관중 수, 수입, 지출 보고서가 나와요.
- 회장님(아버지)의 조건: 시즌 종료 시 **3위 이내 + 구단 자금 30억 이상**. 못 지키면 구단이 매각돼요.
- 시즌이 끝나면 한국시리즈(2위 이내), 시상(홈런왕·타격왕·도루왕·다승왕·탈삼진왕·MVP), 히로인 엔딩이 이어져요.

## 🎵 사운드
음원 파일 없이 Web Audio로 **실시간 작곡·연주**해요. 용량이 0이고 저작권 걱정도 없어요.
- **배경음악 7곡**: 타이틀 테마, 도시 낮(로파이), 도시 밤(재즈), 로맨스(피아노 발라드), 드라마(회장님·부상 장면), 경기장(야구장 오르간), 엔딩/시상식
- 상황에 따라 자동으로 바뀌어요: 히로인이 나오는 대화는 로맨스, 회장님이 나오는 대화는 드라마, 저녁은 재즈. 투구 순간에는 음악이 작아져요.
- **징글**: 승리 팡파르, 패배, 득점권 응원 "차지!", 훈련 레벨업, 호감도 상승
- **효과음**: 타격음 3겹, 관중 웅성거림과 환호, 삼진 때 "우~", 대화 타자음, 발소리, 슈퍼카 엔진음(속도 따라 변함), 경적, 황금공 반짝임, 구매 소리, 폭탄 폭발
- 오른쪽 아래 버튼으로 🔊 전체 → 🔉 음악만 끔 → 🔇 전체 끔 (설정 저장)

## 캐릭터 일러스트 넣기
지금 캐릭터 그림은 코드로 그린 SVG예요. 실제 일러스트로 바꾸는 방법:
1. `assets/characters/` 폴더에 `캐릭터ID_표정.png` 파일을 넣어요. 배경이 투명한 상반신 그림으로, 세로 약 800px이면 돼요.
   - 캐릭터ID: `yuna` `jiwoo` `harin` `sea` `somi` `coach` `chairman`
   - 표정: `normal` `smile` `happy` `sad` `angry` `surprised` `shy` `love`
2. `assets/characters/manifest.js`에 등록해요. 예: `yuna: ['normal', 'smile'],`
3. 등록하지 않은 표정은 `normal` 그림이 대신 쓰이고, 그림이 하나도 없으면 SVG가 나와요.
