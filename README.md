# 사과 팡 (pang_apple)

모바일 위주의 웹 퍼즐 게임입니다. 손가락으로 사각형을 그려 사과를 묶고, 숫자의 합이 **10**이 되면 사과가 터집니다. 제한 시간은 2분이에요.

## 실행

빌드가 필요 없는 단일 파일(`index.html`)입니다. 브라우저로 열거나 GitHub Pages 같은 정적 호스팅에 올리면 됩니다.

## 규칙

- 10 × 15 상자에 1~9 숫자 사과가 놓입니다.
- 드래그로 만든 사각형 안 사과(중심 기준)의 합이 정확히 10이면 터지고, 터진 사과 수만큼 점수를 얻습니다.
- 힌트는 판마다 3번 쓸 수 있습니다.
- 시간이 다 되거나, 더 이상 합 10을 만들 수 없거나, 상자를 다 비우면 게임이 끝납니다.
- 최고 점수는 브라우저에 저장됩니다.
