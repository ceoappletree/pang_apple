# 사과나무 마을

AI 주민과 대화하는 마을 게임입니다. 서버도, API 키도, 빌드 과정도 필요 없습니다.

주민의 두뇌는 세 가지 중에서 고를 수 있습니다 (⚙️ 설정).

| 방식 | 자연어 이해 | 필요한 것 |
| --- | --- | --- |
| **Claude AI** (기본) | 무슨 말이든 알아듣고 매번 새로 대답 | claude.ai 아티팩트로 열기. 보는 사람의 Claude 사용량을 쓰고, 처음 한 번 허용을 물음 |
| 기기 속 LLM (실험) | 작은 모델 수준 | WebGPU 브라우저, 모델 0.5~1.6GB 내려받기 |
| 규칙 기반 AI | 정해 둔 낱말 패턴만 | 없음. 인터넷 없이도 동작 |

Claude AI를 쓸 수 없는 곳(일반 브라우저로 열었거나 허용하지 않은 경우)에서는 자동으로 규칙 기반 AI로 대화합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 휴대폰에서 하려면 폴더를 아무 정적 호스팅(GitHub Pages 등)에 올리거나, PC에서 아래처럼 띄운 뒤 같은 와이파이의 휴대폰으로 접속하세요.

```bash
npx serve .
```

- 이동: 땅을 누르기, 또는 방향키나 WASD
- 대화: 주민을 누르기, 또는 옆에서 스페이스. 아무 말이나 자유롭게 입력할 수 있습니다.
- 줍기: 🍎 🪨 🌷 위를 지나가기
- 📜 마을 수첩: 받은 부탁, 주민별 호감도와 주민이 나에 대해 기억하는 것, NPC끼리 나눈 대화 기록

## 주민

| 주민 | 성격 | 부탁 |
| --- | --- | --- |
| 👵 순이 할머니 | 다정한 과수원 주인 | 떨어진 사과 5개 줍기 |
| 🧔 대장장이 철수 | 무뚝뚝하지만 속은 따뜻함. 미나를 짝사랑 | 광석 3개 가져오기 |
| 👩 상점 주인 미나 | 수다쟁이 소식통. 생선을 팔고 사과·꽃·광석을 사들임 | 철수에게 편지 전하기 |
| 🐱 고양이 모모 | 도도한 마을 고양이 | 생선 주기 (주면 따라다님) |

## Claude AI 방식

`js/claude-ai.js`가 아티팩트의 `sample` 기능으로 Claude에게 묻습니다. 주민의 성격과 말투, 플레이어에 대한 기억, 호감도, 가방, 부탁 상태를 함께 보내고, Claude는 대사와 함께 게임에 반영할 행동(이름 기억, 호감도 변화, 부탁 제안·수락·완료, 선물, 거래, 소문거리, 작별)을 JSON으로 돌려줍니다. 게임은 규칙에 맞는 행동만 반영합니다. 예를 들어 가방에 사과가 모자라면 부탁 완료는 무시합니다.

Claude 호출은 플레이어가 말을 보낼 때만 일어납니다. 주민끼리 나누는 잡담과 소문은 사용량을 쓰지 않도록 규칙 기반으로 돌아갑니다.

## 기억, 호감도, 소문

기억과 상태는 세 방식이 함께 씁니다. 규칙 기반 대화의 핵심은 `js/brain.js`입니다.

- **의도 분석**: 인사, 자기소개, 칭찬, 욕, 사과, 부탁, 거래, 선물, 날씨, 소문 등 30여 가지 의도를 한국어 패턴으로 알아듣습니다. 조사(이/가, 을/를)도 받침에 맞게 붙입니다.
- **대화 맥락**: 주민이 "이름이 뭐니?"라고 물은 뒤 "철민"이라고만 답해도 이름으로 알아듣습니다. 부탁을 제안한 뒤의 "응", "나중에" 같은 짧은 답도 맥락으로 처리합니다.
- **기억**: 주민마다 따로 플레이어의 이름, 좋아하는 것과 싫어하는 것, 플레이어가 한 일을 기억합니다. 진행 상황은 브라우저에 저장되어 다시 열어도 그대로입니다.
- **호감도와 기분**: 칭찬, 선물(주민마다 좋아하는 물건이 다름), 부탁 해결로 오르고 욕하면 떨어집니다. 같은 칭찬을 연달아 하면 덜 먹히고, 같은 말을 반복하면 짜증을 냅니다. 호감도에 따라 말투가 달라집니다.
- **소문**: 주민들은 하루 일정(아침, 낮, 저녁, 밤)에 따라 A* 길찾기로 마을을 돌아다니고, 서로 마주치면 이야기를 나눕니다. 플레이어가 한 주민에게 한 일은 다른 주민에게 전해져 그 주민의 호감도와 첫마디가 바뀝니다. 이름도 소문으로 퍼집니다.
- **생활**: 밤에는 집 앞에서 잠들고, 자는 주민을 두 번 깨우면 화를 냅니다.

## 소리

소리 파일 없이 `js/audio.js`가 Web Audio로 모든 소리를 즉석에서 만듭니다. 브라우저 정책 때문에 화면을 처음 누른 뒤부터 소리가 납니다.

- **배경음악**: 시간대마다 코드 진행과 빠르기, 악기가 바뀌는 잔잔한 곡이 자동으로 연주됩니다. 밤에는 느린 오르골 소리가 납니다.
- **자연 소리**: 아침과 낮에는 새소리, 밤에는 귀뚜라미 소리
- **효과음**: 걸음, 물건 줍기, 동전, 부탁 받기와 완료 팡파르, 호감도 오르내림, 소문이 퍼질 때 속삭임, 새 아침 종소리
- **주민 목소리**: 말할 때 글자 수만큼 "뾰로롱" 소리를 냅니다. 할머니는 중간, 철수는 낮게, 미나는 높게, 모모는 "야옹"으로 시작합니다.
- 상단 🔊 버튼으로 모두 끄고 켜며, ⚙️ 설정에서 음악과 효과음 볼륨을 따로 조절합니다.

## 선택: 기기 속 LLM

⚙️ 설정에서 **기기 속 LLM**을 켜면 [WebLLM](https://github.com/mlc-ai/web-llm)으로 작은 언어 모델(Qwen2.5 0.5B 또는 1.5B)을 브라우저에 내려받아 휴대폰이나 PC 안에서 돌립니다. 역시 API 키나 서버는 필요 없습니다.

- WebGPU를 지원하는 브라우저(최신 크롬, 엣지 등)가 필요합니다.
- 처음 한 번 약 0.5GB 또는 1.6GB를 내려받고, 그 뒤에는 브라우저 캐시를 씁니다.
- 게임 규칙(호감도, 부탁, 기억)은 그대로 `brain.js`가 정하고, LLM은 그 대답을 캐릭터 말투로 자연스럽게 다듬기만 합니다. 작은 모델이 엉뚱한 말(한자, 영어 등)을 내면 규칙 기반 대답으로 돌아갑니다.

## 파일

- `js/data.js`: 아이템, 주민 성격·말투·대사·부탁, NPC끼리의 잡담
- `js/brain.js`: 대화 AI (의도 분석, 기억, 호감도, 부탁, 소문)
- `js/world.js`: 지도, 충돌, A* 길찾기
- `js/audio.js`: 배경음악, 효과음, 주민 목소리
- `js/claude-ai.js`: claude.ai에서 Claude로 대화하기
- `js/llm.js`: 선택 기능인 기기 속 LLM
- `js/main.js`: 그리기, 입력, NPC 행동, 대화 화면
- `tests/brain.test.js`: 대화 AI 테스트 (`node tests/brain.test.js`)
