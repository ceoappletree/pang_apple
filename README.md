# 등대의 밤

목소리가 상황을 읽어 주는 모바일 웹 음성 어드벤처 게임입니다. 폭풍우 치는 밤, 정전된 등대에서 화물선 바다제비호가 암초에 닿기 전에 등대 불을 켜야 합니다.

## 실행

빌드가 필요 없는 단일 파일(`index.html`)입니다. 브라우저로 열거나 GitHub Pages 같은 정적 호스팅에 올리면 됩니다.
음성은 브라우저 내장 음성 합성(Web Speech API)을 쓰므로 별도 서버나 API 키가 필요 없습니다.

## 플레이

- 내레이터가 지금 상황을 한 줄씩 읽어 주고, 다 읽으면 선택지가 나타납니다. `건너뛰기`로 바로 넘어갈 수 있고 `다시 듣기`로 다시 들을 수 있어요.
- 선택할 때마다 배가 가까워집니다. 불빛 없이 어두운 계단을 오르내리면 시간이 더 걸려요.
- 무전 속 선장, 전임 등대지기의 일지, 고양이는 높낮이를 바꿔 읽고, 한국어 음성이 둘 이상이면 다른 음성을 씁니다.
- 엔딩은 5개이며, 찾은 엔딩은 브라우저에 저장됩니다.
- 설정: 목소리 켜기/끄기(끄면 글자로 진행), 내레이터 음성, 말하기 속도, 선택지 읽어 주기, 빗소리·효과음.
- 키보드: `1`~`9` 선택, `S` 건너뛰기, `R` 다시 듣기.

한국어 음성이 없는 기기에서는 기기 설정에서 한국어 TTS 음성을 설치하면 더 자연스럽게 들립니다.

# 닫힌 방의 목소리 (`voice-escape.html`)

밀폐된 방에서 깨어나, 하늘하늘한 찢어진 천을 걸친 여자의 목소리를 듣고 탈출하는 음성 탈출 게임입니다. 방은 4개이고, 방마다 다른 사람을 만나 대화하며 문을 여는 열쇠 단어를 찾습니다.

- 이야기·인물·대사는 Claude 아티팩트의 `sample` 기능으로 판마다 새로 만들어집니다. 처음 시작할 때 Claude 사용 허락을 묻습니다.
- Claude를 쓸 수 없는 환경(일반 브라우저 등)에서는 준비된 이야기 「하얀 커튼 너머」로 진행됩니다.
- 대화창에 자유롭게 말하거나 추천 답변을 누르고, 자물쇠 버튼을 켜면 문에 단어를 직접 입력할 수 있습니다.
- 내레이션, 인물, 그녀의 속삭임은 각각 다른 높낮이·속도의 TTS 목소리로 읽힙니다.
- 이 파일은 Claude 아티팩트 형식(doctype/head 없이 본문만)으로 작성되어 있습니다.
