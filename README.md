# 상판리 발굴기

경북 상주시 모동면 상판리 자기가마터를 지도 위에서 찾아 발굴하는 모바일 웹 게임입니다. 실제 인물(본인 동의)의 기록을 바탕으로 한 이야기 「강석진 발굴기」가 함께 들어 있고, 등장인물의 이름은 모두 가명입니다.

빌드 과정이 없습니다. `index.html`을 정적 호스팅(예: GitHub Pages)에 올려서 엽니다. 진행 기록은 브라우저(localStorage)에 저장됩니다.

## 화면

- **타이틀:** 백화산, 오름가마, 포도밭을 그린 장면. 이야기 시작 / 지도로 / 도감.
- **이야기:** 8장. 장면 그림, 인물 초상, 대화창(탭하면 다음 줄). 강석진(포도 농부), 김태호·이정우(보존회 총무 두 사람), 한지수(학예사), 윤상혁(조사 기관 원장)은 모두 가명입니다.
- **지도(탐사):** 지도를 누르면 탐사대가 그곳으로 걸어갑니다. 어디서든 "여기 땅 살펴보기"로 지표 조사를 합니다.
- **지표 조사:** 땅을 내려다보며 풀을 눌러 뽑고, 문질러 흙을 털고, 보이는 조각을 눌러 줍습니다. 중요 지점(가마터, 상판저수지 물가, 반계리 수도원 뒷산)에 가까울수록 조각이 많이 나오고, 강석진 씨가 조각이 많아질 방향을 알려 줍니다. 아주 가까이에서는 결정적인 증거(불탄 가마 벽 조각, 문양 있는 도자기 편, 세련된 백자편)가 나오고, 그것을 주우면 중요 지점이 발견됩니다.
- **정밀 조사:** 발견한 중요 지점에서 흙판을 곡괭이·꽃삽·탐침으로 파서 조각을 찾는 발굴 퍼즐입니다.
- **도감:** 그릇 10, 명문 조각 10, 답사품 8, 가마 도구 2.
- **소리:** 음원 파일 없이 Web Audio로 합성합니다. 배경음악은 평조 5음 가락을 가야금처럼 뜯는 소리와 장구 장단(세마치 느낌), 낮은 지속음으로 만들고 화면마다(타이틀·이야기·지도·발굴) 분위기가 다릅니다. 효과음은 곡괭이·꽃삽·탐침, 금 가는 소리, 깨지는 소리, 발견 가락, 복원 팡파르, 흙벽 붕괴, 버튼, 대화 글자, 두루마리, 깃발 등입니다. 스피커 버튼으로 켜고 끄며, 설정은 기억합니다. 브라우저 규칙상 첫 탭 뒤에 소리가 납니다.

## 지도

- **지도 서버를 쓸 수 없을 때:** 상판리를 그린 그림 지도로 플레이합니다(실제 지형과 다를 수 있다고 표시).
- **지금(임시):** 카카오 키가 없으면 OpenStreetMap 지도를 씁니다. 상판저수지와 수도원 위치는 OSM 검색(Nominatim)으로 찾고, 가마터는 기록("상판저수지 서쪽 1~1.7km")에 맞춰 저수지 서쪽 1.3km의 **대략 위치**로 둡니다(발견 반경 450m). 로드뷰는 없습니다.
- **나중(카카오):** `src/config.js`에 카카오 JavaScript 키를 넣으면 카카오 스카이뷰(위성)와 로드뷰로 바뀌고, 가마터는 실제 지번(상판리 산58-1, 산69)으로 찾습니다(발견 반경 250m).

## 발굴 내용

- **발굴:** 가마1유적(2015년 발굴)과 가마6유적(2016년 발굴)을 팝니다. 실제 출토 기종 10가지(인화문 대접, 향완, 상감분청 자라병, 고족배, 합, 베개, 장고, 화분과 받침, 제기 보, 돈)의 조각, 가마6유적에서만 나오는 명문 조각 10종(司膳, 寧, 順, 世, 定, 上, 大, 上州京主人, 雙林, 卍), 가마 도구(도침, 갑발)가 나옵니다.
- **답사지:** 상판저수지 물가(물이 빠졌을 때 본 문양 있는 도자기 편, 청화백자로 추정되는 조각, 작은 요강, "大音精製" 글자 조각, 제기 조각 등)와 반계리 수도원 뒷산(분청사기편, 고급 백자편)을 답사할 수 있습니다. 강석진 씨(실제 인물)가 기록한 것만 넣었고, 그의 추정은 추정으로 적었습니다. 
- **표현:** 학계 용례에 따라 '관요'라고 하지 않고 '『세종실록』 지리지의 상품 자기소', '왕실과 중앙 관청에 바친 자기소'라고 씁니다. 확정되지 않은 해석은 "~로 봐요", "아직 밝혀지지 않았어요"로 적었습니다.
- **강석진 발굴기:** 실제 인물(본인 동의)의 블로그 글·보내 온 글과 신문 기사를 바탕으로 했고, 그의 전망과 추정은 그의 말로 밝혔습니다. 모든 등장인물 이름은 가명입니다. 내용은 `src/data.js`의 `G.CAST`, `G.STORY`에서 고칩니다.
- **게임에서 정한 부분:** 합과 자라병이 몇 번 유적에서 나왔는지는 자료에 없어서 두 유적 모두에 넣었습니다. 그릇 그림은 출토품 사진이 아니라 직접 그린 일러스트입니다.

자료 출처: 디지털상주문화대전 「상주 상판리 자기 요지」, 상주박물관 『상주 상판리 자기가마1 유적』(2015)·『상주 상판리 자기가마6 유적』, 대동문화재연구원 지표조사 보고서(2010), 『세종실록』 지리지, 『태종실록』, 성현주(2017)·오영인(2019).

## 카카오 키 넣기

1. developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가하기
2. 앱 키 → **JavaScript 키** 복사 → `src/config.js`의 `KAKAO_JS_KEY`에 넣기
3. 플랫폼 → Web → 사이트 도메인에 게임 주소 등록 (예: `https://ceoappletree.github.io`, 시험용 `http://localhost:8000`)
4. 카카오맵 사용 설정이 있으면 켜기

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `src/data.js` | 상판리 자료(유적, 그릇, 명문, 가마 도구, 이야기, 출처) |
| `src/config.js` | 카카오 키 설정 |
| `src/main.js` | 화면 흐름(타이틀, 이야기, 지도, 발굴 결과, 도감) |
| `src/map.js` | 지도(카카오 / 임시 OpenStreetMap), 위치 찾기 |
| `src/scene.js` | 장면 그림, 인물 초상, 아이콘 |
| `src/field.js` | 지표 조사(풀 뽑기, 흙 털기, 조각 줍기) |
| `src/dig.js` | 정밀 조사 발굴판 |
| `src/audio.js` | 배경음악과 효과음(Web Audio 합성) |
| `src/art.js` | 그릇 SVG 그림 |
| `src/store.js` | 진행 기록 저장 |
