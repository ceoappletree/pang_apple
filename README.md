# 주사위 원정대

주사위 두 개로 보드 둘레를 도는 **인생 보드 RPG**입니다. 몬스터를 잡아 강해지고, 일해서 돈을 벌고, 연애·결혼해 아이를 낳아 키우며 가문을 이어갑니다. 35년차에 깨어나는 마왕을 가문 전원이 함께 물리치는 게 목표입니다. 모바일 세로 화면용이고 다크톤 화면입니다.

## 실행

빌드가 필요 없는 단일 파일(`index.html`)입니다. 브라우저로 열거나 정적 호스팅에 올리면 됩니다.

## 핵심 규칙

- **1라운드 = 1년**: 플레이 가능한 가족이 차례로 주사위를 굴리고, 배우자(NPC)가 움직인 뒤 한 해가 지납니다. 더블이면 한 번 더, 3연속이면 늪행.
- **나이**: 18세에 시작합니다. 36세부터 힘·체력이 줄고 지력은 나이 들수록 오릅니다. 스킬 피해에 지력이 들어가 늙으면 머리로 싸웁니다. 70세부터 노환으로 죽을 수 있습니다.
- **스트레스**: 전투·일·함정으로 쌓이고 여관·술집·가족·축제로 풉니다. 70 이상이면 힘 -20%, 20 이하면 경험치 +25%, 100이면 번아웃으로 한 차례를 쉽니다.
- **연애·결혼**: ⛲ 광장과 🍺 술집에서 대화·선물·데이트로 호감을 쌓고, 100이 되면 청혼합니다. 배우자는 NPC 말로 보드를 돌며 직업 특기(치료, 몬스터 처치, 아이 교육, 장사)로 가문을 돕습니다. 애정이 0이 되면 떠납니다.
- **2세**: 결혼하면 매년 아이가 생길 수 있습니다. 🏠 집을 지날 때 공부·훈련·놀아주기로 키우고, 10살이 되면 직업을 골라 직접 플레이합니다.
- **건설**: 🌾 공터나 🚩 정복한 몬스터 칸에 서 있으면 요새·여관·술집을 짓고 ★3까지 증축합니다. 매년 수입이 들어오고, 요새는 가문 전원의 방어를 올려 줍니다.
- **돈벌기**: 🔨 공사장(힘), 📜 서기소(지력), 건물 수입, 보물, 술집 도박.
- **마왕**: 35년차에 깨어나 살아 있는 모험가 전원과 파티 전투를 합니다. 이기면 무한 모드로 가문을 계속 이어갈 수 있습니다.

진행 상황과 최고 기록은 브라우저에 저장됩니다.
