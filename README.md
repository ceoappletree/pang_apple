# 합주팡

수박 게임처럼 같은 것끼리 합치는 낙하 퍼즐인데, 과일 대신 **악기**를 떨어뜨립니다.
같은 악기 둘이 부딪히면 한 단계 큰 악기가 되고, 새로 생긴 악기는 자기 가락을 연주합니다.
판 위에 여러 악기가 모일수록 하나의 합주가 됩니다.

## 실행

빌드 과정이 없습니다. `index.html`을 브라우저로 열면 됩니다.
(로컬 서버로 열어도 됩니다: `python3 -m http.server` 후 http://localhost:8000)

## 악기 순서 (작은 것 → 큰 것)

| 단계 | 악기 | 연주 |
|---|---|---|
| 1 | 캐스터네츠 | 16분음표 탁탁 리듬 |
| 2 | 마라카스 | 쉬지 않는 셰이크 |
| 3 | 트라이앵글 | 마디 첫 박에 땡 |
| 4 | 탬버린 | 2·4박 찰랑 |
| 5 | 작은북 | 백비트 + 마지막 마디 필인 |
| 6 | 심벌즈 | 두 마디마다 크래시 + 라이드 |
| 7 | 드럼 | 큰북과 탐 필인 |
| 8 | 피리 | 높은 대선율 |
| 9 | 콘트라베이스 | 워킹 베이스 |
| 10 | 색소폰 | 블루스 리프 |
| 11 | 피아노 | 화음 반주 + 8마디 멜로디 |

- 합주는 4마디(8초) 묶음 단위로 돌아갑니다. 새 악기는 생기자마자 소리 내지 않고 **다음 묶음의 첫 박에 다른 악기들과 같은 순간에** 들어갑니다. 그래서 모든 악기의 연주 시작점이 항상 같습니다.
- 대기 중인 악기는 금색 테두리로 첫 박까지 남은 시간을 보여주고, 하단 지휘 막대(4마디 × 4박)가 지금 박자를 보여줍니다.
- 무대가 조용할 때 떨어뜨린 악기는 그 순간이 첫 박이 되어 바로 시작합니다.
- 악기는 **8초**(4마디) 동안 연주하고, **피아노는 16초**(8마디) 멜로디를 첫 음부터 연주합니다. 연주는 항상 묶음이 끝나는 순간에 멈춥니다.
- 모든 악기는 120 BPM과 C–Am–F–G 화음 진행을 공유합니다.
- 같은 악기가 또 나오면 겹쳐 울리지 않고 연주 시간만 늘어납니다.
- 피아노 두 대가 만나면 사라지면서 모든 악기의 16초 대합주가 열립니다(+100점).
- **판 위 악기 모두 연주** 버튼: 지금 판에 있는 악기들을 한꺼번에 연주합니다.
- 점선 위로 악기가 2.6초 넘게 머물면 끝나고, 남은 악기들이 마지막 합주를 합니다.

## 조작

- 터치/마우스: 판을 눌러 위치를 정하고 손을 떼면 떨어집니다.
- 키보드: ← → 로 이동, 스페이스로 떨어뜨리기.

## 구조

- `src/music.js` — Web Audio 합성 음악 엔진(샘플 파일 없음)과 악기별 패턴
- `src/instruments.js` — 악기 정의(크기, 색, 연주 시간)와 캔버스 그림
- `src/game.js` — 물리(matter.js), 입력, 머지, 그리기
- `lib/matter.min.js` — matter-js 0.19.0 (MIT)
