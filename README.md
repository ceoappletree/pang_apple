# 주사위 원정대

주사위 두 개를 굴려 보드 둘레 길을 따라 여러 바퀴 도는 보드 RPG입니다. 몬스터를 쓰러뜨리고 장비를 사며 강해지고, **5바퀴**를 다 돌면 출발점에 깨어나는 마왕을 물리쳐야 합니다. 모바일 세로 화면에 맞췄습니다.

## 실행

빌드가 필요 없는 단일 파일(`index.html`)입니다. 브라우저로 열거나 GitHub Pages 같은 정적 호스팅에 올리면 됩니다.

## 규칙

- **이동**: 주사위 2개의 합만큼 반시계 방향으로 이동합니다. 더블이면 한 번 더 굴리고, 더블이 3번 연속이면 저주의 늪으로 끌려갑니다.
- **바퀴**: 출발점을 지날 때마다 골드와 HP·MP를 회복합니다(딱 멈추면 2배). 대신 바퀴가 늘수록 몬스터가 강해집니다.
- **직업**: 전사(튼튼함) · 마법사(방어 무시 화염구) · 도적(치명타·골드·확정 도주) 중 하나를 고릅니다.
- **전투**: 공격력 + 주사위 눈 − 적 방어만큼 피해를 줍니다. 6은 치명타, 적의 주사위 1은 빗나감입니다. 스킬(MP 3), 포션, 도망, 자동 전투를 쓸 수 있습니다.
- **정복**: 쓰러뜨린 몬스터 칸에는 🚩 깃발이 꽂혀 그 바퀴 동안은 안전하고, 다음 바퀴에 더 강해져 돌아옵니다.

## 칸 종류

| 칸 | 효과 |
| --- | --- |
| 🏁 출발 | 바퀴 보너스(골드·회복) |
| 💧👺🐺💀👹🧛🗿🐉 몬스터 | 길을 따라갈수록 강한 몬스터 8종 |
| 🎁 보물상자 | 골드·포션·행운의 주사위, 가끔 미믹 |
| 🔑 황금열쇠 | 순풍·역풍·소매치기·축복 등 무작위 카드 |
| 🏪 상점 | 포션, 무기·방어구 강화, 생명의 반지, 행운의 주사위 |
| 🏨 여관 | 골드를 내고 완전 회복, 또는 무료 쪽잠 |
| 🕳️ 함정 | 주사위 5 이상이면 회피, 아니면 피해 |
| 🌫️ 저주의 늪 | 더블이 나오거나 골드를 내야 탈출(최대 2턴) |
| ⛩️ 신전 | 공격·방어·최대HP·완전회복 중 축복 하나 |
| 🌀 차원문 | 원하는 칸으로 순간이동 |

진행 상황과 최고 기록은 브라우저에 저장되어, 창을 닫았다가 다시 열어도 이어서 할 수 있습니다.
